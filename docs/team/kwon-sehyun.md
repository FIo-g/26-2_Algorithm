## Task 요약

### Task 2: 실시간 속도 수집기 (시간 민감, 오늘)
- **만드는 것:** `src/routing/speeds/collect.py`
- **넘기는 것:** `data/speeds/raw/` 원본. Task 20(본인)과 Task 21(의종)이 쓴다.
- **완료 기준:**
  - 5분마다 `.json.gz`가 쌓인다.
  - 첫날 저녁 `coverage_day1.txt`(고유 링크 수, 도로명 상위 20개)를 팀에 공유한다.
- **주의:**
  - bbox 남쪽은 37.42다(서초구 남단 37.4285 포함).
  - `clock()`은 수집 1회에 한 번만 부르고, 경과 시간은 `time.monotonic`으로 잰다.
  - API 키는 환경변수로만 다루고 커밋하지 않는다.
  - 11/5 최종 벤치마크 머신에서는 수집기를 끈다.

### Task 4: 정확성 검사 도구
- **만드는 것:** `verify.py`(`path_cost`, `check_result`, `verify_all`), `tests/test_correctness.py`(`EXACT_ALGOS` 등록부)
- **넘기는 것:** 태형 6·7, 의종 8이 등록부에 자기 알고리즘을 추가하고, Task 12가 `verify_all`을 쓴다.
- **완료 기준:** `pytest tests/test_correctness.py` 통과

### Task 5: OSMnx 추출
- **만드는 것:** `osm.py`, `scripts/extract_graph.py`. 그래프 파일 3종 × 3규모
- **넘기는 것:** 모두가 쓴다(관문, E1~E3, 그림 f·g, 매칭).
- **완료 기준:** `.meta.json` 3개. 강남구 예상치는 n ≈ 3,144, m ≈ 8,420, vmax ≈ 80 km/h.
- **주의:**
  - **maxspeed 결측 ≈ 94%** → 데이터 슬라이드에 꼭 밝힌다.
  - 파일은 공유 드라이브에 올리고, 팀원은 다시 받지 않는다.
  - 다시 추출하면 버전을 올리고 공지한다.

### Task 9: 완전탐색 + BFS 부분 그래프
- **만드는 것:** `exhaustive.py`
- **완료 기준:** 격자 경로 수 12 / 184 / 8,512

- **이해 확인:** `docs/explain/exhaustive.md`

### Task 12: 정확성 관문
