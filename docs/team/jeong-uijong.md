## Task 요약

### Task 8: ALT
- **만드는 것:** `alt.py`(`Landmarks`, `build_landmarks`, `preprocess_landmarks`, `alt_heuristic`, `alt`)
- **넘기는 것:** 태형 Task 11(`standard_algos`), Task 14(하한 느슨함), 본인 Task 16
- **주의:**
  - `inf`가 섞인 항은 계산하지 않고 건너뛴다(nan 방지).
  - 이미 고른 랜드마크는 제외하고, 후보가 없으면 k보다 적게 고르고 멈춘다(`k_requested` 기록).
  - 테스트 캐시는 `id(g)`가 아니라 `(g, lm)`을 저장하고 `is`로 비교한다.
- **이해 확인:** `docs/explain/alt.md`(삼각부등식, "느려지기만 하면 재전처리 없이 정확")

### Task 15: 혼잡 시나리오
- **만드는 것:** `congestion.py`
- **주의:**
  - 합성 배율은 가정값이다(발표에서 명시).
  - 대조군은 `hwy_class`가 motorway·trunk인 간선(`*_link` 포함) 전부 + 나머지 10%의 시간을 ×0.5로 줄인다.
- **이해 확인:** `docs/explain/congestion.md`(A*는 vmax를 넘을 때만, ALT는 빨라지기만 해도 깨진다)

### Task 16: E3 + 그림 (c)(d) + 서버 환산
- **만드는 것:** `experiments/e3.py`, `scripts/run_e3.py`, `fig_c`, `fig_d`, `server_ratio`
- **주의:**
  - `g_lb`와 `standard_algos`는 한 번만 만든다(재전처리 없음이 RQ2의 핵심).
  - control 외 시나리오에서 정확 알고리즘이 틀리면 버그이므로 멈춘다.
  - 서버 환산은 Dijkstra 대비 비율로만 낸다.

### Task 19: 현업·문헌 조사 + 공정성 (발표 필수 파트)
- **만드는 것:** `docs/industry.md`
  - 표 1: 누가·무엇을 최적화·어떤 알고리즘·원문 근거
  - 표 2: 문헌 수치 vs 우리 측정
  - 공정성 절
  - 파트 2 구성안
- **완료 기준:** 모든 행에 원문 URL·쪽과 확인자(태형) 이니셜이 있다.
- **주의:**
  - 국내 기업은 알고리즘을 공개하지 않았으므로 "X사가 Y를 쓴다"고 쓰지 않는다.
  - AI가 찾아 준 문헌은 원문을 직접 확인한다.

## 리뷰 담당

- **Task 1·3 (태형)**
  - (u, v) 중복을 거부하는지
  - vmax를 한 번만 계산하는지
  - 카운터 정의가 테스트(`Stats(4,4,5,5)`)와 맞는지
- **Task 6·7 (태형)**
  - A*: `H_SCALE`, 기준 그래프 vmax
  - Bidirectional: `top_f + top_b >= μ`, `bwd` 사용, 함정 그래프 테스트
- **Task 14·17 (태형)**
  - breakeven이 전체 중앙값인지
  - settled 비율이 주 지표인지
  - 그림 (f)의 settled 수가 E2 경향과 맞는지
- **Task 4 (세현):** `ref = inf`일 때 결과도 `(inf, [])`를 요구하는지, 비용 불일치를 잡는지
- **Task 20 (세현):** 방위각 360° 순환 처리, `match_decision.md` 형식
